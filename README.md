# KOOK Music Bot

基于 JKook API 和 KookBC 的 KOOK 音乐机器人。

## 快速开始

### 1. 编译

```powershell
build.bat
```

### 2. 安装

```powershell
install.bat
```

JAR 文件会自动复制到 `plugins` 文件夹。

### 3. 一键编译安装

```powershell
build-and-install.bat
```

## 文件说明

- `build.bat` - 编译项目
- `install.bat` - 安装到 plugins 文件夹
- `build-and-install.bat` - 一键编译安装

## 技术栈

- Java 11+
- JKook API 0.54.2
- KookBC 0.33.0
